# MistraelSL Character Chat Pills

Расширение для **SillyTavern**, которое заменяет беспорядочный список недавних чатов на главной странице удобной библиотекой персонажей.

Вместо десятков отдельных чатов отображается **одна карточка на каждого персонажа**. Нажмите на персонажа, чтобы увидеть только его чаты, найти нужный разговор, переименовать его, удалить или создать новый.

---

## Возможности

### Библиотека персонажей

- На главной странице отображаются персонажи, с которыми уже существуют чаты.
- Отдельные чаты не показываются, пока вы не выберете персонажа.
- Персонажи сортируются по времени последней активности.
- Показываются аватар, имя, дата последнего сообщения и количество чатов.
- Персонажей можно закреплять в начале библиотеки.
- Доступны поиск и фильтры:
  - **Недавние**
  - **Активные**
  - **Частые**
- Есть обычный и компактный режим отображения.

### Управление чатами

После выбора персонажа открывается отдельная панель со всеми его чатами.

В ней можно:

- открыть нужный чат;
- найти чат по названию или содержимому последнего сообщения;
- создать новый чат и сразу задать ему название;
- переименовать существующий чат;
- удалить чат;
- отменить удаление через уведомление;
- добавить важный чат в избранное.

Избранные чаты располагаются выше остальных.

### Последний использованный чат

Чат, в котором было написано самое свежее сообщение, получает отметку:

> **Последний использованный**

Метка определяется отдельно для каждого персонажа. Она не зависит от того, с каким персонажем вы общались последним.

После удаления отмеченного чата список немедленно обновляется, а отметка автоматически переходит на следующий чат по времени последнего сообщения.

### Быстрое закрытие чата

Расширение добавляет кнопку-крестик на верхнюю панель SillyTavern.

Кнопка расположена **слева от кнопки «Настройка ответа ИИ»** и использует стандартное оформление панели SillyTavern.

Она позволяет одним нажатием:

- закрыть текущий чат;
- вернуться на главный экран;
- не искать действие «Закрыть чат» в меню отправки сообщения.

Крестик отображается только тогда, когда открыт чат.

## Поддержка телефонов и планшетов

Интерфейс адаптирован для разных размеров экрана:

- компьютеров;
- ноутбуков;
- планшетов;
- телефонов.

На телефоне можно выбрать количество персонажей в строке:

- 2 персонажа;
- 3 персонажа;
- 4 персонажа.

Кнопки управления чатами увеличены для сенсорных экранов, а интерфейс автоматически упрощается на небольших устройствах.

Расширение также учитывает системное уменьшение анимаций и отключает лишние эффекты на сенсорных устройствах.

---

## Совместимость с темами

Расширение использует цвета и переменные текущей темы SillyTavern:

- цвет текста;
- цвет фона;
- цвет границ;
- акцентный цвет;
- оформление верхней панели.

Для тем с нестандартными или отсутствующими переменными предусмотрены запасные цвета. Также добавлен упрощённый фон для браузеров без поддержки размытия.

## Оптимизация

Для работы с большими библиотеками используются:

- ленивая загрузка аватаров;
- асинхронное декодирование изображений;
- кэширование списка недавних чатов;
- кэширование форматирования дат;
- отложенный поиск;
- ограниченное наблюдение за изменениями интерфейса;
- пропуск отрисовки элементов за пределами видимой области;
- облегчённые эффекты на мобильных устройствах.

## Язык интерфейса

Язык определяется автоматически по языку SillyTavern:

- русская SillyTavern → русский интерфейс;
- английская SillyTavern → английский интерфейс.

Русский язык поддерживается во всех основных элементах расширения, включая кнопки, поиск, уведомления, ошибки и подтверждения.

## Установка через SillyTavern

1. Откройте **SillyTavern**.
2. Перейдите в раздел **Расширения**.
3. Нажмите **Установить расширение**.
4. Вставьте ссылку на репозиторий:

   ```text
   https://github.com/MistraelSL/MistraelSL-CharacterChatPills
   ```

5. Подтвердите установку.
6. Перезагрузите страницу сочетанием `Ctrl + F5`.

---

## Ручная установка

Скопируйте папку `MistraelSL-CharacterChatPills` в каталог расширений пользователя:

```text
SillyTavern/data/default-user/extensions/
```

Итоговый путь должен выглядеть так:

```text
SillyTavern/data/default-user/extensions/MistraelSL-CharacterChatPills/
```

Внутри папки должны находиться:

```text
index.js
manifest.json
style.css
```

После установки перезапустите SillyTavern и обновите страницу через `Ctrl + F5`.

---

## Обновление

Если расширение установлено через ссылку на GitHub:

1. Откройте управление расширениями SillyTavern.
2. Найдите **MistraelSL Character Chat Pills**.
3. Запустите проверку обновлений.
4. После обновления перезагрузите страницу.

При ручной установке замените файлы расширения новыми версиями.

---

## Хранение настроек

Локально в браузере сохраняются:

- закреплённые персонажи;
- избранные чаты;
- выбранный вид карточек;
- количество персонажей в строке на телефоне.

Сами персонажи и чаты продолжают храниться стандартными средствами SillyTavern. Расширение не создаёт отдельную библиотеку и не переносит данные в сторонние сервисы.

---

## Ограничения

- Сейчас расширение ориентировано на обычные чаты с отдельными персонажами.
- Групповые чаты пока не отображаются в библиотеке.
- Некоторые старые чаты могут не содержать корректной даты. В таком случае отображается подпись **«Дата неизвестна»**.
- После крупных обновлений рекомендуется использовать `Ctrl + F5`, чтобы браузер не загружал старые файлы из кэша.

---

## Сообщения об ошибках

При обнаружении проблемы укажите:

- версию SillyTavern;
- версию расширения;
- используемый браузер;
- устройство: компьютер, планшет или телефон;
- последовательность действий, после которой появилась ошибка;
- сообщения из консоли браузера, начинающиеся с `MistraelSL Character Chat Pills`.
